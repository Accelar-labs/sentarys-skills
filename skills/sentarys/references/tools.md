# Sentarys MCP tools

Server: `https://api.sentarys.com/v1/mcp`. 115 tools. Descriptions are the ones the server sends to the agent; the live list is always `tools/list`.

## Clips, uploads, editing, export and dubbing

| Tool | What it does |
|---|---|
| `generate_teleprompter_script` | Writes short spoken paragraphs for a guided camera recording. Costs 10 credits per target minute, proportionally rounded, minimum 5. Returns a jobId; poll get_teleprompter_script. Failed writing refunds the charge. |
| `get_teleprompter_script` | Read the status and spoken paragraphs of your recording script. Free. |
| `get_clip_action_track` | Read measured sports crop paths of an owned clip. Free; timestamps are source seconds. Missing paths mean the existing framing was retained. Does not detect, analyze, charge or render. |
| `prepare_clip_playback` | Request the project 720p playback copy on demand. Free, asynchronous; the editor plays the original while queued. Does not analyse or render clips. |
| `get_clip_payoff` | Returns the exact source phrase or timed visual resolution selected by the story planner, plus kept ranges. Free. Legacy clips may have no marker. |
| `change_editing_type` | Changes the editing template of an already analysed clips project and replaces the current analysis clips using the cached analysis. No new analysis credits are charged. It fails if processing or if the cache is missing. Poll get_project for new clips. This replaces current clips and their edits. Use highlights for complete sports plays. |
| `add_captions_to_video` | Caption a video link in its original frame, or turn an uploaded audio recording into an audiogram with cover, animated waveform and captions. For audio: start_upload(kind=full_video, aspect?, captionStyle?), upload and complete_upload(startProcessing=false), optionally start_upload a JPG/PNG/WEBP cover with that projectId and wait for list_project_files to show it probed, then call this tool with projectId and uploadId. Audio defaults to 9:16; aspect accepts 1:1 and 16:9 too. Video links start automatically after import. Costs 50 credits per source minute, rounded up in tens, minimum 200. Failed jobs refund the reservation. Poll get_project, then get_captions_file. Video sources support dub_clip; audiograms currently do not. |
| `get_captions_file` | Return caption text and an authenticated API download URL for any clip with EDL words, including dubbed clips. Uses the words of the selected version. Free. |
| `get_account` | Credit balance, plan and what each action costs, in credits. Call it before a paid action to check the balance, and after one to confirm what it cost. Renders, exports and edits are free. Example: before clipping a 40 minute podcast, 40 x 200 = 8,000 credits are needed. |
| `list_templates` | Everything the other tools accept as a choice: clip templates (what the editor looks for and how it edits: podcast, viral, tiktok, gameplay...), caption styles, looks, accent colours, faceless and long edit styles, dubbing languages, variation batch sizes and Discover categories. Read it once before creating projects or editing clips. |
| `list_projects` | The account's video projects, newest activity first: clips projects (one source cut into Shorts), long edits, recaps and faceless videos, with status and clip counts. Use the projectId with get_project. |
| `select_import_range` | Resumes a project at import_needs_range. Choose whole source seconds within importSourceDurationSeconds; the section must fit importMaxDurationSeconds. Analysis timestamps are relative to the imported section. Credits are charged only when analysis starts. |
| `create_clips_project` | Turn a YouTube, TikTok or Instagram video (a podcast, interview, stream, talk) into short vertical clips with captions, hook and edit. The video is imported, then analysed automatically; clips appear in get_project in a few minutes (about 5 to 15 minutes for a one hour video). Costs 200 credits per minute of the source (minimum 1,000), charged when the analysis starts; failed runs are refunded. Example: {"url":"https://www.youtube.com/watch?v=...","templateId":"podcast"}. For a file on disk use start_upload instead. Optional startSec/endSec import just that section. Videos beyond the import limit pause at import_needs_range; resume with select_import_range. |
| `get_project_transcript` | The full timed transcript of an owned video project, or null before transcription finishes. Read it when you need the source speech rather than polling it with project status. |
| `get_first_ready_clip` | Returns the first rendered, ready clip of your project with signed playback and download links, even while the remaining source is still being analysed. Read-only and free. Poll every 30 seconds; never restart processing to wait for a clip. |
| `get_project` | Status, progress and clips of a project. Poll it while status is importing, queued, analyzing or rendering (every 20 to 30 seconds). Each clip has its clipId, title, duration, hook, scores, status and, when rendered, a previewUrl (720p) and exportUrl (1080p) that anyone can open for 10 minutes, plus stable API links. nextAction says what to do next. |
| `start_processing` | Starts the paid work of a project: captioning an entire video, finding and editing the clips of an uploaded video, editing a long video or recap from its files, or creating a faceless video from its brief. Link projects start on their own (when the balance is short they clip the part it covers from 0:00), so only call it after start_upload/complete_upload with startProcessing=false, when files of a long edit are ready, to clip another part of a clips project (windowStartSec and windowEndSec, whole seconds, at least 60 s; new clips join the existing ones and only that part is charged), or to retry a failed project. Returns the credits charged. Never call it twice for the same project; poll get_project instead. |
| `start_upload` | Starts a private upload of a video file from disk (MP4, MOV or WEBM), or MP3, M4A, WAV, AAC, OGG audio with kind=full_video. An image uploaded with an existing full_video projectId is its single cover; upload the cover before processing audio. Without projectId it creates a clips project (or full_video with kind=full_video) for it; with the id of a long edit or recap it adds the file to that project; with toLibrary=true it goes to My library. Returns signed part URLs: split the file into partSizeBytes chunks (for example `split -b <partSizeBytes> -d -a 3 video.mp4 part_`), PUT each chunk to its uploadUrl in order (`curl -sS -X PUT --upload-file part_000 "<uploadUrl>" -D -` and keep the ETag response header), then call complete_upload with every partNumber and ETag. URLs expire in 10 minutes; get more with sign_upload_parts. |
| `sign_upload_parts` | Fresh signed URLs for parts of an upload started with start_upload (URLs last 10 minutes; at most 32 parts per call). Pass the same projectId, uploadId and, for project files or library uploads, the assetId. |
| `complete_upload` | Finishes an upload after every part was PUT: pass each partNumber with the ETag header its PUT returned. For a clips project the analysis then starts by default (startProcessing=true, charged like links). For long edit files and library uploads the file is checked and prepared; see list_project_files or get_library. |
| `get_clip_framing` | Read the saved framing and source text regions of an owned clip, in source seconds. Free; uses the selected clip visual analysis and local measurements already saved in the edit. Does not analyze or render. |
| `get_clip_word_edges` | Read word boundaries and speech-safe fades for an owned clip. Free; reports forced alignment coverage separately from ASR fallback. Does not analyze or render. |
| `get_clip` | One clip in full: duration, hook, caption style and position, accent, look, emoji, keywords, why the moment was chosen, scores, the caption lines with their times (seconds from the start of the clip), status and media links (previewUrl, exportUrl valid for 10 minutes). Read it before edit_clip, and poll it after render_clip or dub_clip. |
| `get_clip_notes` | Reads saved editorial recommendations and measured technical findings. Free, no AI call or render. Editorial notes do not block delivery or apply edits automatically. |
| `edit_clip` | Changes one clip, like the editor chat: trims, cuts in the middle, caption style and position, hook text and duration, accent colour, look, progress bar, emoji, framing, title, and effects at spoken phrases (zooms, emoji, big words, shakes). Put every change for the clip in one call. Times are seconds from the start of the clip; phrases must be words as spoken in the captions (see get_clip lines). Free. The edit is saved; call render_clip to get a new file. Example: {"trimStartSec":1.5,"captionStyle":"karaoke","hookText":"He lost $2M in one night","zoomAt":[{"phrase":"federal prison","strength":"strong"}]}. |
| `download_clip` | Returns the existing 1080p export or queues it on demand, free. Watching uses the 720p preview. Poll get_clip until exportUrl is ready; no extra email is sent. An explicit request for an available export records download intent, not completed transfer or social publication. |
| `render_clip` | Renders a clip with its latest edit: mode=export makes the final 1080p MP4 (default), mode=preview a quick 720p check. Free. Returns right away; poll get_clip until status is ready and exportUrl (or previewUrl) is set, usually 1 to 4 minutes. |
| `dub_clip` | Makes a dubbed copy of a ready clip in each language (translated, cast to matching voices, lip timed captions). Each language becomes a new clip in the same project. With review=true, translation stops at needs_review: get_dub_draft, update_dub_draft, then approve_dub. Optional glossary adds or overrides account terms for this request. voiceMatch=true makes each speaker's dubbed voice sound like their own (cloned from their speech in the clip; adds 150 credits per minute, minimum 100). Costs 300 credits per minute of clip per language (minimum 300 each); failed languages are refunded. Example: {"languages":["es","pt-BR"]}. Poll get_clip with each new clipId. |
| `get_dub_draft` | Read source and translated phrases, overlays and title before approving a dub. Only in review. Free. |
| `update_dub_draft` | Edit translated title, phrases or overlays by their existing i. Text must be nonempty and at most 3 times source length plus 80 characters. Only in review. Free. |
| `approve_dub` | Queue voices and preview from the reviewed text, without translating again or charging additional credits. Duplicate approval returns the same job id. Poll get_clip for the finished video. |
| `list_dub_glossary` | Read account terms used by dubbing. A null translation preserves a term exactly, null language applies to every language. Free. |
| `add_dub_glossary_term` | Add an account term (at most 200). Omit translation to preserve spelling exactly; omit language to apply to all targets. Free. |
| `delete_dub_glossary_term` | Delete one owned glossary term. Free. |
| `create_variations` | Makes N versions of a ready clip for testing: new hooks every time, and optionally other caption styles, colours, music and an opening on the payoff line (the brand kit applies when set). Costs 60 credits per variation; failed ones are refunded. Exports of variations are free. Returns a batchId; poll get_variations. |
| `get_variations` | Without batchId: the variation batches of a project. With batchId: the batch progress and each variation with its hook, status and links (preview and 1080p export when exported). |
| `export_variations` | Queues 1080p exports for the chosen variations, or for every finished one not exported yet when clipIds is omitted. Free. Poll get_variations until exportUrl is set. |
| `get_job` | Status of one background job by jobId (dubs return one per language): queued, running, done or failed, with progress and error. get_project and get_clip usually say more; this is for a single job. |
